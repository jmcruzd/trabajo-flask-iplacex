# Trabajo Flask - Programación Web - Iplacex

## Para ejecutar el proyecto:
1. Clonar el repositorio
2. Crear entorno virtual dentro del directorio principal del proyecto (sólo si es necesario): python3 -m venv venv 
3. Activar el entorno: source venv/bin/activate
4. Instalar flask: pip install flask
5. Ejecutar el proyecto: python3 main.py
6. Abrir http://127.0.0.1:5000/ en el navegador
